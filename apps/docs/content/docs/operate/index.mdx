Start with Oore's complete one-Mac installation. It keeps `oored`, the local
web client, a managed Direct macOS runner, and automatic local artifact storage
on one Mac. Add network, identity, or storage infrastructure only when your
team needs it.

## Choose an operating path

- [Choose a supported deployment](/operate/deploy) before exposing Oore beyond
  loopback or splitting roles across hosts.
- [Connect the hosted UI](/operate/access/hosted-ui) or
  [self-host the static UI](/operate/access/self-hosted-ui) when you need a
  different browser client.
- [Add a Direct macOS runner](/operate/runners/direct) when builds should run
  on another Mac.
- [Configure artifact storage](/operate/storage/artifacts) when the automatic
  local provider no longer fits.

## Maintain and recover

- [Monitor Oore](/operate/maintain/monitor), then
  [create and verify a backup](/operate/maintain/backups/create) before an
  upgrade.
- [Upgrade Oore](/operate/maintain/upgrade) on the installation's current
  channel.
- Start with [Troubleshoot Oore](/operate/troubleshoot) when behavior changes.
  Use [Reset an Oore installation](/operate/recover/reset) only after you have
  exhausted the narrower recovery path.

For current product boundaries, see
[Review known limitations](/operate/known-limitations).
