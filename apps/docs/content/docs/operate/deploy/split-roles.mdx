---
title: 'Split Oore across machines'
status: planned
description: 'Prepare separate control, runner, and browser machines through the v0.2 component flow.'
---

The v0.2 installer does not collect network, proxy, or account settings.

Install the Oore control shell on each machine. Then select the role for that machine.

## Local Oore machine

Use this role for the backend and its local browser client:

```bash
oore install --role local-oore
```

## Runner machine

Use this role for a separate build runner:

```bash
oore install --role runner
```

## Custom component machine

Use the advanced role only when the standard roles do not fit:

```bash
oore install \
  --role advanced \
  --component oore-web
```

The browser will collect the backend URL, protected transport, identity provider, and proxy details.

The fallback archive currently supports macOS. Native Linux packages will provide the same role flow without Apple build components.

## Security boundary

The role choice does not prove that a remote HTTP connection is safe. Use HTTPS or an encrypted private network between machines.

Do not put shared secrets in installer arguments or reusable shell history.
