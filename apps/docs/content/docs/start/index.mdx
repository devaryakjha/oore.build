Start here if you have a Flutter project and one Mac. The default journey ends
with a downloaded debug APK built from a local Git repository.

## Begin the default path

<Cards>
  <Card title="Check that your Mac is ready" href="/start/prerequisites">
    Confirm the supported host, repository, and Android build prerequisites
    before installing Oore.
  </Card>
</Cards>

Oore guides you through four focused jobs:

1. Check the Mac and local repository.
2. Install the stable release and managed Direct macOS runner.
3. Use the first loopback sign-in to initialize Local Only.
4. Create a project and run **Quick Debug APK**.

This path does not require External Access, an identity provider, GitHub or
GitLab, signing credentials, or object storage.

## Already partway through?

- If Oore is installed, [open it for the first time](/start/first-run).
- If you can already reach the **Dashboard**, [build your first debug APK](/start/first-build).
- If you need other people or non-loopback access, finish the local build first,
  then continue to [Team and access](/team).
