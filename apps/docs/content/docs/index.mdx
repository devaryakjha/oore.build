Oore is for Flutter teams that want builds and artifacts to stay on hardware
they control. Start on one Mac, build a debug APK from a local Git repository,
and expand only when your team needs more.

## Start on one Mac

<Cards>
  <Card title="Build your first debug APK" href="/start">
    Install Oore in Local Only, create a project from a repository on your Mac,
    and run **Quick Debug APK**.
  </Card>
</Cards>

The default install includes `oored`, the `oore` operator CLI, a local web
client, a managed Direct macOS runner, and automatic local artifact storage.

![Oore dashboard showing system status, active builds, and recent build activity](/demo-dashboard.png)
