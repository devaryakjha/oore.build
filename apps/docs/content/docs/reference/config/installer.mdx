Use a native Oore package when one is available for your system.

The fallback installer remains available for macOS archives and unsupported package flows. Download it before you run it:

```bash
curl -fL https://oore.build/install -o oore-install.sh
less oore-install.sh
bash oore-install.sh
```

The fallback installer performs four tasks:

1. It resolves one release.
2. It verifies the archive checksum.
3. It installs the Oore control shell and bundled transition components.
4. It runs `oore install` for the machine-role choice.

It does not configure authentication, networks, proxies, accounts, sources, projects, or product settings.

## Machine roles

| Role | Purpose |
| --- | --- |
| `local-oore` | Run Oore and a local runner on this machine. |
| `runner` | Use this machine only as a runner. |
| `shell-only` | Keep only the Oore control shell. |
| `advanced` | Select explicit components. |

Run a noninteractive role selection:

```bash
OORE_MACHINE_ROLE=runner bash oore-install.sh
```

Select advanced components:

```bash
bash oore-install.sh \
  --role advanced \
  --component oored \
  --component oore-web
```

## Release selection

| Variable | Default | Purpose |
| --- | --- | --- |
| `OORE_VERSION` | `latest` | Select `latest` or an exact release tag. |
| `OORE_CHANNEL` | `stable` | Select `stable`, `beta`, or `alpha`. |
| `OORE_INSTALL_ROOT` | `~/.oore` | Set the archive installation root. |
| `OORE_MACHINE_ROLE` | None | Set the role when no terminal input is available. |
| `OORE_COMPONENTS` | None | Set comma-separated component IDs for the advanced role. |

The native package writes the install source and scope. The control shell records these values in its install plan and receipt.

Run `oore install` again to change or resume the machine plan.

Product setup continues in the browser after the selected local services are ready.
