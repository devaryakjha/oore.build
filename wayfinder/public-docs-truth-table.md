# Public documentation truth table

Status: research resolution for
[#198](https://github.com/oore-ci/oore.build/issues/198), at baseline
`66e56785394960f280b7c37244ed72b1dccca4bc`.

This is the factual handoff for public-documentation writers. It reconciles the
current authored pages against executable behavior, public contracts, generated
OpenAPI, product UI labels, and focused tests. It does not decide the deployment
contract, information architecture, voice, URLs, or the public rewrite itself.
Page dispositions remain in the
[public documentation disposition ledger](https://github.com/oore-ci/oore.build/blob/f9a9699d767012b8ed409c6622f1d2254cc8e37a/wayfinder/public-docs-page-ledger.md).

## How to use this table

Evidence is ordered by authority:

1. Parsers, handlers, state machines, and command definitions.
2. Focused behavior tests and actual `--help` output.
3. Product UI labels and client state.
4. Checked generated OpenAPI, with runtime/export drift called out explicitly.
5. Existing authored pages only when they agree with the sources above.

“Conflicting pages” means the named authored page must not be copied forward
without applying the writer rule. “No additional conflict” in the page ledger
means this pass found no material contradiction beyond the cross-cutting rules
in this document; it does not mean the page should keep its current structure or
voice.

## Canonical public vocabulary

| Concept                                      | Canonical public term               | Internal/API literals that may appear in reference material | Writer rule                                                                                                                |
| -------------------------------------------- | ----------------------------------- | ----------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| Loopback-only operation                      | **Local Only**                      | `runtime_mode: "local"`                                     | Use **Local Only** in prose and UI instructions. Use `local` only when showing an exact payload, enum, flag value, or log. |
| Non-loopback operation                       | **External Access**                 | `runtime_mode: "remote"`                                    | Use **External Access** in prose. Do not use “Remote mode” as the public product name.                                     |
| Oore authenticates with an identity provider | **External Access (OIDC)**          | `remote_auth_mode: "oidc"`                                  | Use this form when the subtype matters.                                                                                    |
| An upstream proxy authenticates users        | **External Access (Trusted Proxy)** | `remote_auth_mode: "trusted_proxy"`                         | Name the trusted peer CIDR, identity header, and distinct shared proof when explaining the boundary.                       |
| Source-provider area                         | **Sources**                         | integrations, repositories, installations                   | Use the UI label **Sources** for navigation. Use the API nouns only in API reference.                                      |
| Backend daemon                               | **`oored`**                         | daemon/control plane                                        | Keep daemon/runtime lifecycle on `oored`.                                                                                  |
| Operator CLI                                 | **`oore`**                          | setup, auth, runner, config, update, backup                 | Keep setup/operator/admin flows on `oore`.                                                                                 |
| Build executor                               | **Direct macOS runner**             | external runner; `OORED_RUNNER_MODE=external`               | Do not teach embedded or hybrid execution as supported.                                                                    |

Public vocabulary is fixed even where older UI copy still says “Remote
(OIDC)” or “Remote (Trusted Proxy)”. The setup mode UI is therefore evidence of
a product-label drift, not permission to reintroduce “Remote” in public prose.
